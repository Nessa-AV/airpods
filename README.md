## Key Website Features & UX Advantages

- Dedicated Product Pages: Every item features its own customizable page with color selection, interactive image galleries, dynamic pricing, and quantity controls.
- Seamless Interactive Cart: Slide-out drawer cart allows users to manage items, adjust quantities, and view real-time subtotal calculations without reloading the page.
- Intuitive Navigation: Fast modal views, clean breadcrumbs, and effortless switching between the catalog and product details for a smooth user journey.
- Responsive Design: Layout and user interface are fully optimized for seamless performance on smartphones, tablets, and desktops.
- Structured Content Blocks: Built-in sections for technical specifications, customer review metrics, warranty options, and shipping details.

---

## Tech Stack

- HTML5: Clean, semantic code structure.
- CSS3: Modern design standards, flexbox/grid layouts, responsive breakpoints, and smooth animations.
- JavaScript: Lightweight vanilla JS handling state management, cart operations, dynamic rendering, and UI interactions without heavy external dependencies.
